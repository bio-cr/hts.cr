    def each_cigar(& : Tuple(Char, UInt32) -> ) : self #

    Iterate over CIGAR operations without allocating a Cigar object or copying the encoded CIGAR words out of the BAM record. This yields the same {op, len} tuple shape as Cigar#each, but reads from this record's underlying BAM memory during the block. Use #cigar when an independent, retained CIGAR object is needed.

    def qual_string #

    Return base qualities as a Phred+33 QUAL string.
