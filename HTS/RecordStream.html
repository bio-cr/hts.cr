    module HTS::RecordStream(T)

    Overview

    Collection helpers for readers whose each reuses a record. Implementing readers must provide each_copy for retained results, and records must support clone. A record returned by an early exit from each must continue owning its native storage. Each traversal consumes records from the reader's current position.
